# Marketing-Analysis-Dashboard

1 About the Project
This project is a Marketing Analysis Dashboard created using
Microsoft Power BI.

The dashboard presents key business information in a visual and
easy-to-understand format. It helps users explore sales amount, profit,
quantity, customer activity, product categories, and payment methods.

2 The report uses two data tables: 
Orders and Details. 
Users can also filter the report by state and order quarter to explore different
parts of the data.

3 Tools Used
- Microsoft Power BI -- To build the dashboard and create visual
  reports.
- Power BI Visuals -- To display information through cards,
  charts, and slicers.
- CSV files -- To provide the Orders and Details data.

4 Dashboard Features
The dashboard includes the following visuals and filters:

1. Total Profit -- Displays the total profit from the Details
   table.
2. Average Order Value (AOV) -- Displays the aggregated AOV field
   from the Details table.
3. Total Sales Amount -- Displays the total amount from the Details
   table.
4. Total Quantity -- Displays the total quantity.
5. Profit by Month -- Shows profit across months using the order
   date.
6. Sales Amount by State -- Compares the sales amount across
   states.
7. Profit by Sub-Category -- Shows profit for different product
   sub-categories.
8. Quantity by Category -- Compares quantity across product
   categories.
9. Sales Amount by Customer -- Displays sales amount by customer.
10. Quantity by Payment Mode -- Shows quantity by payment method.
11. State Filter -- Allows users to filter the report by state.
12. Quarter Filter -- Allows users to filter the report by order
    quarter.

5 Dataset Information
The report model contains two main tables:
1. Orders
The Orders table includes:
- Order ID
- Order Date
- CustomerName
- State
- City
2. Details
The Details table includes:
- Order ID
- Amount
- Profit
- Quantity
- Category
- Sub-Category
- PaymentMode
- AOV
The two tables use Order ID as their common field.

6 How to Use the Dashboard
- Use the State filter to view data for a selected state.
- Use the Quarter filter to focus on a particular order quarter.
- Review the cards to see the main summary values.
- Explore the charts to compare profit, sales amount, quantity,
  customers, categories, and payment methods.

7 How to Open the Project
1. Download the .pbit file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. When prompted, connect the required Orders.csv and Details.csv
   files.
4. Make sure the files contain the columns listed in the Dataset
   Information section.
5. Load or refresh the data and explore the dashboard.
Note: The template contains references to local CSV file locations
from the original setup. You may need to update the file paths when
opening it on another computer.
